# gov.uk SAME-GUIDE candidates, batch 5 — 2026-09-28.
#
# The shape batches 2 and 3 were deliberately built to AVOID, now sought on
# purpose. Two sections of one gov.uk guide share a `content_id`, so the
# fetcher classifies them as same-guide rather than Tier 1, and they populate
# the `same_guide` reporting row -- which stands at 7 of a 60 target while
# `natural cross-document` is at 28 of 60.
#
# This is not a lesser category. The separation is real at retrieval time: a
# retriever genuinely returns two passages from different URLs that it cannot
# reconcile, and nobody manufactured the split. What it is not is evidence that
# organisations publish rules and exceptions in separate DOCUMENTS, which is
# why it is reported as its own row rather than folded into Tier 1.
#
# Kept in a separate file from the cross-document pairings of the same URL set,
# because mixing the two would make neither row countable.
