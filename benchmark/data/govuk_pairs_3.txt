# gov.uk Tier-1 candidates, batch 3 — 2026-09-28.
#
# Same shape that worked in batch 2: a public-facing route guide paired with
# the Immigration Rules appendix or the caseworker guidance for that route.
# Batch 2 returned 12 of 15 distinct documents and zero same-guide with this
# structure, against batch 1's 7 of 17.
#
# Global Business Mobility is the richest source here: one appendix and one
# caseworker guidance govern five separate route pages, so each route pairs
# against both. That is the general-rule-plus-route-specific-carve-out shape
# the benchmark is about.
#
# The six Temporary Work routes were supplied without an appendix, so they are
# paired against the eligible-occupations list and against each other. Expect
# `disjoint` rather than `refinement` from cross-route pairs -- which is worth
# having, since `disjoint` is one of the four relations and mined data has
# produced only two of them so far.
