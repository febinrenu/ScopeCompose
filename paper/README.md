# The manuscript

*Where Do the Conditions Go? Stage-wise Attribution of Condition Loss in Chunked Retrieval-Augmented
Generation*, prepared for the Journal of Trends in Computer Science and Smart Technology (IRO Journals). It
follows the publisher's template in `../irojournals-scopus-paper-template-LaTex/`.

## Build

```bash
python -m study.report            # from the repository root: numbers.tex and tables/*.tex
python -m study.figures           # figures/*.pdf
cd paper
tectonic -X compile main.tex      # main.pdf: the full manuscript with authors and biographies
tectonic -X compile review.tex    # review.pdf: anonymised review copy
python check_paper.py             # journal limits and project rules
python check_tables.py            # Tables 3 and 5 rescored from the raw outputs with the official scorer
python make_docx.py               # submission/Where_Do_the_Conditions_Go.docx
python make_submission.py         # submission/Where_Do_the_Conditions_Go_LaTeX_source.zip
```

Any XeLaTeX or pdfLaTeX installation works in place of Tectonic. Under XeTeX the text font is TeX Gyre
Termes; under pdfLaTeX it is the template's Times (`mathptmx`).

## Files

| Path | Content | Edited by hand? |
|---|---|---|
| `main.tex` | preamble and title block (template, unchanged except for listed additions) | yes |
| `review.tex` | defines `\reviewcopy` and inputs `main.tex`: no authors or biographies | yes |
| `sections/*.tex` | abstract, sections, statements, references, biographies | yes |
| `numbers.tex` | one macro per reported number | **no**: generated by `study.report` |
| `tables/*.tex` | the seven tables | **no**: generated by `study.report` |
| `figures/*.pdf` | the figures | **no**: generated by `study.figures` |
| `figures/authors/` | author photos (cropped) | yes |
| `references_verified.md` | each reference checked against its primary source | yes |
| `response_to_reviewers.md` | five review rounds and the responses | yes |
| `submission/` | the Word file and LaTeX .zip (gitignored; rebuilt by the two scripts) | no |

## Rules the checks enforce

`check_paper.py` passes only if all of these hold:
- the PDF is at most 25 pages;
- there are at most 25 references, every reference is cited, and they are numbered in order of first citation;
- the abstract is 150–250 words with no citation, and there are 4–6 keywords;
- no `\pending` marker remains;
- no line is overfull by more than 2 pt;
- no number is typed into the running text instead of a generated macro.
